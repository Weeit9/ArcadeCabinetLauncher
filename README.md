# Arcade Cabinet Launcher

A custom arcade-style game launcher built for a dedicated arcade cabinet setup. Designed to provide a clean, intuitive interface for browsing and launching games in a cabinet environment.

---

## 🎮 Overview

This project was developed as a custom launcher system for an arcade cabinet. It organizes installed games into a simple interface optimized for controller or arcade input, allowing users to easily navigate and launch games without a traditional desktop environment.

This launcher was also built for use in an academic setting and tailored for a professor’s arcade cabinet project at Arkansas Tech University.

---

## ✨ Features

- Clean, controller-friendly UI
- Game browsing and selection system
- Full-screen arcade mode interface
- Smooth navigation optimized for cabinet use
- Lightweight and fast performance
- Easily expandable game library system

---

## 🛠️ Technologies Used

- C#
- XAML
- File system integration
- Input handling system
- Game execution/launcher logic
